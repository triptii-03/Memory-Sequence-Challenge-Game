# Memory-Sequence-Challenge-Game
It is an interactive browser based memory challenge game built with HTML , CSS and JavaScript . It tests users' pattern recall by generating progressively longer sequences. 
It generates a sequence of colors that you must remember and repeat correctly. With every successful level, the sequence becomes longer and more challenging.
 
Features:
- Interactive gameplay
- Progressive difficulty with increasing levels
- Randomly generated color sequences
- Real-time user input validation
- Score/Level tracking
- Restart game after game over
- Responsive and user-friendly interface
  
Technologies Used:
- HTML5
- CSS3
- JavaScript
